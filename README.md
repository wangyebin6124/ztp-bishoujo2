# 僵尸房车公园 ～美娘大作战 2.0～

经典 Ninja Kiwi《Zombie Trailer Park》(2010) 的本地同人复刻 **2.0 版**：
在 1.0「萌娘百科美娘大战僵尸娘」的基础上，加入 **FGO 英灵**（含 **2.6 妖精圆桌领域** 全员）与更多萌娘百科美少女，
新增 **七大职业克制**、**全员独立被动**、**战前编队** 三大系统。

双击 `index.html` 即可游玩（建议本地静态服务器，如 `python -m http.server`）。

### 📋 战前编队
- 34 名角色中挑选 **6 人**出征，只有编队成员可在战斗中部署
- **第 6 位是助战位：部署费用 6 折**
- 支持来源筛选（FGO2.6 / FGO / 萌娘百科）与职业筛选、推荐编成、自动保存
- 快捷键 `1-6` 部署对应编队成员

## 快捷键

| 键 | 功能 |
|---|---|
| `1`-`6` | 部署编队成员 |
| `Q`/`W`/`E`/`R` | 超级召唤 / 宝具 |
| `P` / `Esc` | 暂停 |
| `S` | 倍速 |
| `M` | 静音 |
| `H` | 无敌版开关 |

## 文件结构

```
index.html            入口
style.css             界面样式（含编队界面）
js/data.js            34人花名册 / 职业 / 被动 / 敌人 / 关卡 / 建筑 / 宝具
js/game.js            引擎：职业克制 / 被动 / 光环 / AI导演 / 渲染
js/ui.js              HUD / 编队界面 / 各屏幕
js/main.js            启动 / 资源清单（数据驱动）/ 事件接线
js/save.js            进度 / 编队 / 作弊偏好 (localStorage)
js/fx.js, js/audio.js 特效与音效（与 1.0 相同）
assets/               sprites(抠图立绘) / cards(灵基符卡+头像) / wiki(来源与清单)
tools/                抓图与加工脚本、语法烟测
```
